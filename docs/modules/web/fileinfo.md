# `class FileInfo extends HTMLTableElement`
This is a general form/view for files in listings (Downloads, News, Documents, ...).

It's mostly shown in [**help**](./help.md) popup's (so only visible when using a
regular mouse - not available on mobile phones etc. w/ touch screens).
